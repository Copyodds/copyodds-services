# API 错误码约定

后端统一返回以下信封结构：

```json
{
  "code": 40911,
  "data": {
    "message": "Trading wallet prerequisites not completed",
    "details": {
      "hint": "Complete prerequisites..."
    }
  },
  "requestId": "req_123"
}
```

## 错误码分段

- `400xx`：请求参数与字段校验错误
- `401xx`：登录态失效或会话无效
- `403xx`：权限不足、共享密钥无效、风控拒绝
- `404xx`：资源不存在或功能未开放
- `409xx`：状态冲突、幂等或前置条件未满足
- `410xx`：资源已下线或不可再操作
- `429xx`：频率限制
- `500xx`：服务内部错误或依赖不可用

## 当前已启用的核心错误码

- `40001`：通用请求错误
- `40011`：字段校验失败
- `40101`：未登录或凭证无效
- `40111`：会话已失效
- `40301`：权限不足
- `40321`：共享密钥无效
- `40331`：交易被风控拦截
- `40401`：资源不存在
- `40421`：功能未开放
- `40901`：通用冲突
- `40911`：状态冲突或前置条件未满足
- `41001`：资源不可再操作
- `42901`：请求频率过高
- `50001`：内部错误
- `50021`：依赖服务不可用

## 前端展示建议

- `400xx`：提示用户修正输入
- `401xx`：触发重新登录
- `403xx`：提示无权限或当前不可操作
- `404xx`：提示资源不存在或功能未开放
- `409xx`：提示刷新后重试，或完成前置步骤
- `429xx`：提示稍后再试
- `500xx`：统一提示服务异常，不展示内部细节
